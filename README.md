# AI-Assisted Automated Grading System

An intelligent system designed to assist educators in automatically grading and evaluating student submissions with high accuracy and consistency.

## Key Features
- **Automated Evaluation:** Evaluates student answers against marking schemes/rubrics.
- **Detailed Feedback Generation:** Provides constructive feedback based on evaluation results.
- **Fairness & Consistency:** Reduces bias and manual grading time.

## Tech Stack
- **Language:** Python
- **AI/ML:** PyTorch / Transformers / OpenAI API / Scikit-learn
- **Tools:** Jupyter Notebook, VS Code
